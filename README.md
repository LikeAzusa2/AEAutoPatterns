# AE Auto Patterns / AE 自动样板

为 AE2 添加自动样板终端。选择目标物品后，终端递归分析配方、复用已有样板，并按依赖顺序生成缺失的 AE 样板。

## 安装

- Minecraft **1.21.1**、Java **21**、NeoForge **21.1.169+**（21.1 系列）。
- AE2 **19.2.13 至 19.3 之前**、GuideME **21.1.1+**。JEI 为可选依赖。
- 将模组 JAR 放入客户端和服务端的 `mods` 文件夹。

## 快速上手

1. 将自动样板终端装到 ME 线缆侧面，确认网络有电且有可用频道，然后右键打开。
2. 搜索并选择目标物品，点击「分析」。在左侧处理待选配方和未解决路线，也可打开「配方树」查看和调整依赖。
3. 放入空白样板，点击「开始/继续」。每生成一张新样板消耗一张空白样板。
4. 将结果装入样板供应器，或配置「目标供应器」并开启自动输出。实际合成仍需配置对应机器并供应原料。

准星对准已安装的终端，按 **G** 可打开 GuideME 游戏内指南。


## 构建与许可

使用 Java 21 运行 `./gradlew build`（Windows 可用 `gradlew.bat build`），JAR 输出到 `build/libs/`。
