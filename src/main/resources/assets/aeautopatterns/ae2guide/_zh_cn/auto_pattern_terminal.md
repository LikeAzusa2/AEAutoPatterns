# 自动样板终端

<ItemImage id="aeautopatterns:auto_pattern_terminal" />

## 使用步骤

1. **连接终端。** 将终端安装在 ME 线缆侧面，确认网络有电并分配了频道，然后右键打开。
2. **选择目标。** 在搜索框输入物品名称或 ID，点击搜索结果。也可以拿起物品后点击“选取光标物品”；安装 JEI 时还能把 JEI 中的虚拟物品拖到搜索框。
3. **分析路线。** 点击“分析”，等待状态显示“准备就绪”。左侧待处理栏会列出需要确认配方的材料和未解决路径。点击待选材料，在 3×3 配方预览中用左右箭头挑选，再点击“确认配方”。未解决项可点击定位，然后切换配方、原料或设为“外部供应”。
4. **生成样板。** 把 AE 空白样板放进空白样板输入槽。界面会显示所需数量；确认路线已解决后，点击“开始/继续”。每生成一张新样板消耗一张空白样板，结果进入输出栏。
5. **安装样板。** 从输出栏取出样板，放进 AE 样板供应器。工作台、切石机和锻造台样板由分子装配室执行；处理样板要连接对应机器并准备燃料、能量及输入输出。

在左侧“待处理材料”栏可滚动列表，勾选多项后批量设为外部供应。

## 可选功能

- 想生成熔炉等机器配方时，先勾选“处理样板”，再分析。机器燃料和工作条件需要自行配置。
- 点击“配方树”查看完整材料路线；点材料可调整配方、原料或外部供应设置。
- 点击“目标供应器”选择网络内的设备，再开启“自动输出”，生成的样板会直接上传。

## 原理与常见情况

终端从目标向下读取支持的配方，再按依赖顺序生成缺失样板。例如 `A ← B + C`、`B ← D`，生成顺序为 **D、B、A**；共享材料只生成一张。已有网络样板会跳过编码，同时继续检查它所需的材料。每生成一张新样板消耗一张空白样板；分析和编码不会消耗配方原料。

- 显示“待选择配方”：在左侧点击材料，预览并确认一个配方。
- 显示“路线未解决”或“不支持”：点击左侧对应材料，换配方或设置外部供应。
- 等待空白样板：补充空白样板后点击“开始/继续”。
- 输出栏已满：取出样板后继续；网络断开时先恢复供电和频道。

按住准星对准终端并按 **G** 可再次打开本指南。背包中悬停终端物品并按住 GuideME 指南键也可打开。
