# 自动样板终端

<ItemImage id="aeautopatterns:auto_pattern_terminal" />

为目标及其缺失的下游材料自动编写 AE 样板。**只消耗空白样板，不消耗配方原料。**“完成”表示所选路线的样板已备好；实际自动合成仍需要安装样板、配置机器并供应基础原料。

## 查看说明

准星直接对准已安装的终端，按 **G** 打开本页。可在 **控制 → AE 自动样板 → 查看终端说明** 中改键。在背包内，将鼠标悬停在终端物品上，**按住 GuideME 的查看指南键**（默认也是 G）同样能打开。也可从 AE 指南的“物品、方块和机器”分类进入。

## 第一次使用

1. 将终端安装到 ME 线缆侧面，确保网络通电且有可用频道，右键打开。面板颜色随线缆改变。
2. 搜索物品名称或 ID，点击结果设为目标。也可在背包光标上拿起物品，再点 **选取光标物品**，保留其数据组件。选取不会消耗物品。
3. 点 **分析**，查看待生成、网络已有、输出栏已有及外部供应材料。出现“待选择配方”时，点击标记材料，用左右箭头翻看 **3×3 配方预览** 并确认；其他独立分支会继续分析。
4. 将 AE **空白样板**放入输入槽。路线全部解决后，点 **开始/继续**；每 tick 最多生成一张，写入 **27 格输出缓冲区**。待生成数量就是本次空白样板需求。
5. 将结果装进[样板供应器](ae2:items-blocks-machines/pattern_provider.md)。工作台、切石机、锻造台原生样板交给[分子装配室](ae2:items-blocks-machines/molecular_assembler.md)；处理样板需要连接相应机器和输入、回收通道。

## 查看和微调配方树

分析结束后点 **配方树**。目标位于顶部，材料逐层向下分支。拖动空白处平移，滚轮缩放；左侧材料清单可搜索、滚动，点击条目直接定位。点击树节点后，会浮起详情和操作面板。

可切换配方、切换标签原料，或设为 **外部供应**，停止展开该材料。共享材料可能出现在多个分支中；修改任意一处会同步影响其他位置并重新分析，编码时仍只生成一份。树图最多展示 4096 个位置，未展开分支会明确标记，和分析容量分别计算。

## 常用选项

- **处理样板**：默认关闭。开启后生成适配器支持的机器配方；关闭时仍能复用已部署或输出栏已有样板。新处理样板悬停提示中有高亮配方 ID。
- **物品替换 / 流体替换**：沿用 AE 原生选项，默认物品关闭、流体开启。只作用于支持的输入，不会替代任意机器条件。
- **自动上传**：选定网络中可见的样板供应器后开启，结果直接写入指定设备。目标不存在或已满时暂停，换目标或腾出空间即可。

机器配方须有对应适配器；流体、化学品路线需要相应联动，Mekanism 化学品还需要 **Applied Mekanistics**。概率副产物、温度等条件仅作提示，不会冒充 AE 保证的产出。能量、燃料及机器环境由玩家配置。**无需 JEI**，未安装时直接使用服务端配方分析。

## 简要原理

例如 `A ← B + C，B ← D`：终端查询服务端支持的配方和网络、输出栏样板，展开原料，按依赖先后编写缺失样板，即 **先 B、后 A**。没有支持配方的 D 列为外部供应；明确标记“不支持”的配方需另选路线或手动指定外部供应。

已有样板只跳过该产物的编码，仍检查它的输入。网络里暂时有材料库存不会停止补全；普通存储中的样板物品不算已部署。多个分支共用同种材料时，规划和编码只计算一份。

分析在服务端分步执行，识别循环并尝试其他路线。压缩/解压互转循环可将重复的基础材料设为外部输入；玩家手动锁定的循环路线会明确报错。微调时复用未受影响的分析。默认最多 **512 层、16384 个候选材料**；大整合包可能需要更长时间。

## 遇到暂停或问题

| 状态 | 处理方法 |
|---|---|
| 待选择配方 | 点击标记材料，翻页预览并确认。 |
| 路线未解决 / 循环 | 点击底部提示定位出错步骤，换配方、原料或设为外部供应。 |
| 空白不足 / 输出满 | 补充空白或取走结果，条件满足后继续生成。 |
| 网络离线 | 检查供电和频道。 |
| 需要重新分析 | 网络节点、所选样板、配方或世界加载发生变化，重新分析；已有结果保留。 |
| 不支持 | 换受支持的路线、安装对应适配器，或明确将材料设为外部供应。 |

**暂停**需手动继续；**取消**结束任务并保留库存。悬停状态行可查看分析进度和诊断。同一终端的任务、选项和库存由所有使用者共享。
